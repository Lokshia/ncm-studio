# NCM Studio

一个离线运行的 Windows 本地音乐整理工具。选择网易云音乐的下载目录，扫描 NCM 文件，勾选歌曲，将内部的原始无损 FLAC 保存到指定位置。

无需登录账号，不连接音乐服务，不上传文件，不自动下载歌曲。

## 直接使用

1. 下载 `NCMStudio-0.1.0-windows-x64.zip`，**完整解压**到自己有写入权限的文件夹。
2. 打开其中的 `NCMStudio.exe`。不能只取出 EXE；`_internal` 是必需的运行环境。
3. 在网易云音乐中下载完成后，选择其设置中的**下载目录**，不是软件安装目录或缓存目录。
4. 选择另一个保存位置。下载目录和保存位置不能相同，也不能互相包含。
5. 点击「扫描文件」，勾选需要的歌曲，然后点击「转换所选」。

结果保存在所选位置的 `Music` 文件夹，保留原来的子目录结构。可以将里面的歌曲与同名 LRC 一起复制到播放器 SD 卡的 Music 目录。封面保存在 FLAC 文件内部，无需额外复制 cover 文件。没有内嵌或 NCM 封面的歌曲，不会自动联网补图；当前版本也不导入旁边单独的 cover.jpg。

本程序不控制网易云下载，不支持缓存文件、其他加密格式、拖放或联网搜索。

## 音质与文件保护

- 只提取 NCM 内部的 FLAC，不重采样、不升频、不重新编码音频帧。
- 支持带完整样本数与音频 MD5 的 16-bit、24-bit FLAC。内部为 MP3 的文件会显示原因，不会伪装成无损。
- 保存前完整解码整首歌曲，验证样本数与 PCM MD5，并检查整理标签前后压缩音频帧一致。
- 保留原文件。碰到已有同名文件不覆盖；只有源文件和结果的 SHA-256 都与历史记录一致时才跳过。
- 可以停止。已完成的歌曲保留，当前临时文件清理；突然断电或强制结束进程可能遗留临时文件。
- 从 NCM 补充歌名、艺术家、专辑和 JPEG/PNG 封面；保留音频中已有的其他标签。这里只验证数据没有变化，不能证明上游录音本身没有升频。
- 同目录、同名的 LRC 原样复制。歌词缺失、编码问题或不匹配的同名歌词会提示，不会凭空生成歌词。
- 不支持的文件会单独显示，一首失败不会中断后续歌曲。

应用目录下的 `.ncm-studio/settings.json` 只记住两个文件夹位置。输出目录的 `.ncm-studio` 保存去重校验记录、临时文件与处理报告。不要将这些个人记录上传 GitHub。复制到 SD 卡时只需音乐和歌词，不需要这些记录。

首次发布版面向 Windows 10/11 x64；其他系统与 Windows ARM 未验证。程序未做代码签名，不能承诺没有系统信誉提示；遇到安全警报请先核查来源与哈希，不要关闭安全防护。

## 从源码运行

安装 Python 3.12 x64，然后在项目目录中运行：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe main.py
```

开发与打包时需要下载依赖；打包后的程序不需要联网或另装 Python。

```powershell
.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
.venv\Scripts\python.exe -X utf8 tools/build.py
```

打包脚本先运行测试，再生成 `dist/NCMStudio/`、便携 ZIP、源码 ZIP 和 `SHA256SUMS.txt`。它只收集白名单源码、文档和许可证，不收集音乐、目录设置或本机处理记录。测试音频全部由测试程序合成，不使用实际歌曲。
